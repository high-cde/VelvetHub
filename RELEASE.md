# VelvetHub release — Radar / VR.Crew integration

Questa release porta nel Live Club il modulo Radar della Carne come pagina `/radar`. Il gioco viene distribuito come build statica sotto `client/public/radar`, senza modificare il server OAuth o il database del club.

Sono inclusi age-gate, consenso revocabile, ruoli ludici Master/Mistress/Slave, Rubina e Kali come guide AI, missioni, Sigilli locali e inventario cosmetico non esplicito con polsini, seta, collant a rete, pizzo, segnali VR e aftercare.

È incluso l’adapter `integrations-velvet-bot.mjs` per Discord, Facebook Page e WhatsApp Cloud API. L’adapter resta disabilitato senza segreti e applica policy di sicurezza. Nessuna pubblicazione automatica, media esplicito, incontro, pagamento, claim o airdrop è incluso.
