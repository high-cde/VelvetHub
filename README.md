# VelvetHub Supreme // Red Velvet & ZDOS Sovereign Ecosystem

Hub multimediale e Telegram Mini App nativa (18+ / BDSM / Game-Fi) integrata con i progetti creativi **Red Velvet**, guidata dal bytecode **ZLang** e protetta dal protocollo di comunicazione cifrata E2E **ZComm**.

## 📂 Struttura del Repository
- `public/`: Interfaccia frontend della Mini App Telegram e dashboard Sovereign (supporta GitHub Pages).
  - `index.html`: Dashboard unificata con Vault, ZComm chat, Flesh Grid e Mistress Z-01.
  - `assets/`: Asset visivi ufficiali Red Velvet (`red-velvet-garden-ritual.jpg`, `red-velvet-hero-luxe.jpg`, ecc.).
- `api/`: Backend Node.js / Express nativo senza dipendenze PHP o legacy.
  - `server.js`: Endpoint ZComm, gestione Vault DRM ZLang e stato del sistema Sovereign.

## 🚀 Deployment
Progettato per l'esecuzione nativa su VPS (utente `xdosdev`) e sincronizzato con l'ecosistema **ZDOS**.
